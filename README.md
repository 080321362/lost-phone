# 失物招领 · 一部旧手机（v2）

一个 30-40 分钟的网页解谜：你在出租车上捡到一部旧手机，机主在查妹妹的失踪案，最后也失联了。

在线地址：https://080321362.github.io/lost-phone/

## 怎么玩

```bash
cd lost-phone
python -m http.server 8080
```

打开 http://127.0.0.1:8080/ 。手机端是全屏体验。

## 谜题结构（6 个主线谜题）

```
锁屏通知里的生日 3·17 → 密码 0317
   ↓
聊天（妈妈）→ 机主身份：林知夏
备忘录（加密笔记，密码来自 9 月 12 日）→ 灯下读书会 / 西河路 17 号 3F
通话留言 → 西河路 17 号
相册（咖啡杯反光）→ 灯下读书会 3F
浏览器历史 → 论坛帖「d x e c」→ 地下二层
   ↓
最终判断：23:00 知夏在哪？
   ↓
四个结局：报警 / 独自前往 / 交给妈妈 / 关机
隐藏照片（相册第 3 次进入出现）决定「独自前往」是真结局还是走错
```

## 应用

锁屏、聊天、备忘录、相册、通话、邮件、浏览器/地图、关于。

## 结局

| 结局 | 触发 |
|---|---|
| 报警 | 选「报警」 |
| 真结局 | 6 个线索全解 + 看过隐藏照片 + 选「自己去 3F」 |
| 独自前往（走错） | 线索不全时选「自己去 3F」 |
| 交给妈妈 | 选「把手机交给妈妈」 |
| 关机 | 选「关机，不再管」 |
