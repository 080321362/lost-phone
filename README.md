# 失物招领 · 一部旧手机

一个 15-20 分钟的网页解谜小品：你在出租车上捡到一部旧手机，想找到失主是谁。

## 怎么玩

```bash
cd lost-phone
python -m http.server 8080
```

打开 http://127.0.0.1:8080/ 。手机上也能玩（页面是移动优先的）。

## 谜题结构

```
锁屏密码（通知里的生日 → 0317）
   ↓
主屏：备忘录 / 聊天 / 相册 / 关于
   ├─ 聊天：确认失主身份（林知夏）与「拾光书店」
   ├─ 备忘录：天台门锁、老地方、不告而别的理由
   └─ 相册：第 3 次进入触发隐藏照片 → 天台地点
        ↓
结局选择：打给妈妈 / 关机留下
        ↓
两个结局（归还 / 留下），隐藏照片会改变归还结局的细节
```

## 设计要点（从拆解中学到的）

- **拟真界面**：手机壳、状态栏、锁屏通知、钥匙盘，先把"这是一部真手机"立住。
- **密码来自数据**：锁屏密码不是猜的，是通知里生日蛋糕上的日期。
- **线索分散**：身份在聊天里，地点在相册里，动机在备忘录里，缺一块就拼不全。
- **重复访问藏内容**：相册第 3 次进入才同步出新照片，复刻"第 3 次访问下载 PDF"的手法。
- **结局看选择**：归还与留下两个结局，隐藏照片决定归还结局的温度。

## 文件

| 文件 | 作用 |
|---|---|
| index.html | 锁屏 + 密码盘 |
| home.html | 主屏应用网格 |
| notes.html | 备忘录（动机/地点线索） |
| chat.html | 聊天（身份线索） |
| photos.html | 相册（隐藏照片） |
| ending.html | 结局选择与结算 |
| style.css | 手机外壳与所有界面样式 |
| app.js | 存档、密码、聊天、相册、结局逻辑 |

## 存档

进度存在浏览器 `localStorage`，刷新不丢。结局页可以「重新开始」清档。

## 验收记录

独立 QA 试玩后修复的问题：

| 级别 | 问题 | 修复 |
|---|---|---|
| P1 | 矮屏（390×667 / 1366×768）锁屏键盘被裁切 | 增加矮屏媒体查询，压缩时钟/通知/按键，键盘底部回到视口内 |
| P2 | 清档后可直接访问结局页 | 结局页也纳入解锁门禁 |
| P2 | 打开任意会话都算线索 2 | 只有打开「妈妈」会话才计入 |
| P2 | 聊天气泡过窄，短句提前折行 | 调整气泡容器的 max-width 与 flex 规则 |

复验：390×667 与 1366×768 下键盘可见；未解锁访问 notes/chat/photos/ending 均跳回锁屏；周店长会话不计数、妈妈会话计数；短消息单行显示；重开清空 `lp_*` 存档。
